FEATURED PROJECT

Meet Student Toolkit.

One application. Multiple useful tools. Student Toolkit is an Android application created to make everyday student tasks simpler and more convenient.

What is Student Toolkit?

Student Toolkit is an all-in-one academic companion developed under Senan Ahmad Studios. Instead of switching between multiple applications for everyday school tasks, students can access several useful tools from one place.

Why I Made It

I wanted to create something practical for students. I noticed that everyday academic activities often require different tools, so I decided to bring useful student features together in a single application.

What's Inside?

Student Toolkit brings together a collection of features designed around everyday student needs.

🧮
Scientific Calculator A calculator interface inspired by scientific calculators.
📅
Timetable Keep your school schedule organised in one place.
📊
Grades A convenient space for keeping track of grades.
📝
Planner Organise your plans and everyday academic tasks.
📚
Assignments Keep assignment information organised.
📄
PDF Support A place for working with academic PDF documents.
🌙
Dark Mode Choose a darker appearance for the application.

Built Through Experimentation

Student Toolkit grew through multiple development versions, testing, improvements, and refinements. The project represents a hands-on journey into application design and development.

The Vision

The goal is to keep improving the experience and explore new ways technology can help students organise their academic lives. Student Toolkit is a continuing project built around learning and innovation.
